BIRDLOG COMMUNITY UPDATE
=========================

The normal user home page is a Bird Community feed.
The old dashboard cards for Sightings, Species, Places, and Recent are not shown on the Community home page.

Community features:
- Public Instagram-style bird photo posts
- Post author/profile view
- Like/unlike
- Comments
- Share/copy post link
- Direct Message from a user's profile
- Search birds, users, and hashtags
- Notifications for likes, comments, and messages
- Report post

Follow and Save are intentionally removed from the normal user interface.
Every new observation submitted by a logged-in user becomes a community post.

ADMIN FILES/ADMIN UI were not changed in this update.

- Same-bird notifications: when a user posts a bird already posted by other users, those previous posters receive a notification. The new post is still allowed.
